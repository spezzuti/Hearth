# Milestone 13: Library foundation

Hearth 0.10 turns universal capture into a real room rather than a future promise.

## Delivered

- Library added to persistent room navigation.
- Up to 200 recent captures available instead of the Home preview limit.
- Search across text, domains, and connected projects.
- Everything, Links, Ideas, and Notes shelves.
- Link cards with guarded external opening.
- Captures connected to the project active when they were saved.
- Responsive catalog and Librarian desk layout.
- Persistent Librarian conversation with plain-language local retrieval.

## Current boundary

Librarian uses the local catalog and a natural retrieval-oriented personality. Provider-backed
reasoning, editable metadata, tags, pinning, deduplication, URL enrichment, and fresh repo/skill
recommendations remain deliberately separate follow-up work.

## Next

Completed in Milestone 14: real organization controls, guarded URL metadata, and a fresh repo and
skill discovery feed tuned to the active project.
