# Milestone 21: Archive recovery room

Hearth 0.18 opens Archive as a calm place to find finished context and recover the few things that
are genuinely reversible.

## Delivered

- A real Archive room and restart-persistent route.
- Unified records for prior Return Packs, archived Library links and notes, let-go ideas, completed or
  discarded Workshop handoffs, and Hearth file-edit recovery.
- Literal in-room search across titles, summaries, projects, paths, and visible record details.
- Category filters with quiet counts rather than scores, streaks, or an activity feed.
- A list-and-detail workspace with readable full context and copyable records.
- One-click return of archived Library items to their active shelves.
- One-click return of let-go ideas to Studio as resting ideas.
- Two-step file-edit Undo through the existing verified backup and stale-file refusal boundary.
- Read-only truth for Return Packs and closed handoffs instead of false resume behavior.
- No project selection, terminal, resident-context, or filesystem change from opening, searching,
  selecting, or copying Archive records.
- Compact 1080×720 containment and renderer-reload coverage.

## Current boundary

Archive is a recovery projection, not a complete event log or version-control browser. It does not
store terminal output, replay resident conversations, recreate deleted files, reapply restored edits,
or reopen a completed Claude Code process.

## Next

Strengthen project continuity around Archive and Home: let a user deliberately orient from a
historical record into its related project or room without silently changing context, then begin the
bounded remote/mobile companion foundation.
