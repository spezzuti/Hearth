# Milestone 16: Studio foundation

Hearth 0.13 opens Studio as a real room for ideas that deserve somewhere to exist before they
become work.

## Delivered

- Studio promoted from a future-room placeholder to a persistent route.
- Direct idea capture without requiring a prefix or turning the idea into a task.
- Resting, Pursuing, Let go, and All views with clear counts.
- Explicit **Pursue**, **Let go**, **Let it rest**, and **Bring back** decisions.
- Reversible idea state persisted in SQLite with decision timestamps.
- Existing universal-capture ideas included automatically.
- Selected-project connection and Library tags kept visible on idea cards.
- A warm creative-worktable surface that remains contained at the minimum desktop size.
- No scores, streaks, points, artificial urgency, or extra household resident.

## Current boundary

Pursuing an idea records a deliberate attention decision. It does not create a repository, folder,
task list, terminal session, or agent assignment. Let go is not deletion; the full idea remains
recoverable.

## Next

Let a pursued idea develop through natural household conversation, then explicitly promote it into
a new or existing project without losing its origin. Bounded text edits remain the next deeper
Project capability.
