# Milestone 12: Git corroboration and Critic review

Hearth 0.9 distinguishes Claude Code's execution claims from evidence visible in the
workspace and makes independent review a single deliberate action.

## Delivered

- Stable project identity and root captured on each Maker proposal.
- Automatic path-level comparison against the current Git working tree.
- Matched, partial, mismatch, unavailable, and checking states.
- Explicit missing-reported and additional-observed path evidence.
- Clear non-attribution language beside every corroboration.
- One-click completed-report handoff to Critic.
- Critic receives the structured report, discrepancies, and current bounded diff.
- Terminal transcript, Maker conversation, and terminal ownership remain isolated.
