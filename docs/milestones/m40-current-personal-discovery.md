# Milestone 40: Current, personal Discovery

Hearth 0.35.0 turns the Library's live feed into a quieter, more deliberate recommendation shelf.

## Delivered

- Separate **Curated**, **Dependable**, **Emerging**, **Skills**, and **Hidden** views.
- Visible shelf freshness plus relative update age on every recommendation.
- A four-hour refresh window with the existing honest last-good-shelf fallback.
- Stronger visible-metadata evidence for skill collections and emerging projects.
- Specialist-noise suppression that yields when saved Library vocabulary shows a real interest.
- Modest ranking signals derived from saved collections and tags as well as reversible feedback.
- Exact saved-link suppression in both the core feed and the rendered shelf.
- Short recommendation reasons that explain selected-project and saved-Library fit.

## Verification

- Unit coverage proves credible skill evidence, emerging-project substance, specialist filtering,
  saved-interest exceptions, taste ranking, and dependable/emerging balance.
- Real Electron coverage checks all five shelf controls, freshness language, feedback reversal,
  readable card copy, and compact-window containment.
- A private copy of the real Hearth database refreshed against current GitHub results with no saved
  URL overlap and balanced dependable, emerging, and skill lanes.
- At 1280 pixels wide, the Library, catalog, and document remained horizontally contained.
- The installed Hearth database and PersonalOS source remained untouched during the proof.

## Principle

Discovery should save attention. Popularity earns consideration, relevance earns placement, and the
user always makes the final decision.
